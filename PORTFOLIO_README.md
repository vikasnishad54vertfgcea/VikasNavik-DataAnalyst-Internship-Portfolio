## 📌 Task 4 — Data Storytelling & Statistical Validation

**Repo:** [Task_4-ApexPlanet-](https://github.com/vikasnishad54vertfgcea/Task_4-ApexPlanet-)

### 📊 Key Findings — Real Superstore Data

| Metric | Value |
|--------|-------|
| Total Revenue | **$2,297,201** |
| Total Profit | **$286,397** |
| Profit Margin | **12.5%** |
| Revenue Growth | **+51.4%** (2014 → 2017) |
| Orders at a Loss | **18.7%** |
| Losses from High Discounts | **$135,376** |

### 🔬 Hypothesis Testing

**H₀:** Discounts do NOT significantly reduce profit per order
**H₁:** Discounts significantly reduce profit — high discounts destroy margins

| Group | Avg Profit per Order |
|-------|---------------------|
| No Discount | **$66.90** ✅ |
| With Discount | **-$6.66** ❌ |
| p-value | **~0.000000** — Reject H₀ ✅ |
| 95% Confidence Interval | [$64.40, $82.72] |

**Verdict:** Discounts are a statistically proven destroyer of profit at 99.99% confidence. High-discount orders (>20%) generated **$135,376 in total losses.**

**Skills:** `SciPy` `T-Test` `Chi-Squared` `Confidence Intervals` `PowerPoint` `Jupyter`
